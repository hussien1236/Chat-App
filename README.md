# Real-Time Chat Application

A multimedia real-time chat application built with Laravel, React.js, MySQL, Redis, WebSockets, and Reverb. Enables instant messaging, file/audio attachments, emojis, and scalable communication for large user bases.

## Features
- Real-time messaging with text, files, audio, and emojis
- Group creation and management
- Role-based access and secure communication
- Horizontal scaling for high system capacity
- Message broadcasting using Redis Pub/Sub

## Tech Stack
- **Frontend:** React.js
- **Backend:** Laravel
- **Database:** MySQL
- **Caching / Pub-Sub:** Redis
- **Real-Time:** WebSockets, Reverb

## Usage
- Register or login to start chatting  
- Create groups, send messages, files, audio, and emojis in real-time
